# Offensive Security Labs

This folder contains ethical, authorized exercises performed only in personal labs, CTFs, or intentionally vulnerable training environments.

## Planned or Completed Projects

1. Nmap reconnaissance against an authorized lab target
2. Vulnerability validation in a training environment
3. Burp Suite web-application testing lab
4. Metasploit exercise against an intentionally vulnerable machine
5. Remediation report following a lab assessment

## Scope and Ethics

Activities are limited to systems I own, controlled lab environments, CTF platforms, or targets where I have explicit authorization.

The purpose is to understand attacker techniques and improve defensive detection and remediation.
