\# Kali Linux Security Lab



\## Objective



Use Kali Linux in a controlled lab environment to practice cybersecurity tools and understand security-testing workflows.



\## Environment



\- Personal lab computer or virtual machine

\- Training platform or course lab

\- Authorized systems only



\## Tool Used



\- Kali Linux



\## What I Practiced



\- Navigating the Kali Linux environment

\- Using security tools in authorized lab exercises

\- Performing basic reconnaissance and network analysis

\- Supporting vulnerability-assessment practice

\- Documenting observations and remediation recommendations



\## What I Learned



Kali Linux provides a security-focused environment used for authorized testing and learning. Using it in controlled labs helps build familiarity with security tools and supports a stronger understanding of defensive security.



\## Ethical Scope



All activity was limited to systems I owned, training environments, CTF platforms, or systems where I had explicit permission. This work was completed for ethical learning and defensive awareness.
