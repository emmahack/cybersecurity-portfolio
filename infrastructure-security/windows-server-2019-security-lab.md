\# Windows Server 2019 Security Lab



\## Objective



Use Windows Server 2019 in a lab or authorized environment to practice secure server administration and security monitoring.



\## Environment



\- Personal lab or training environment

\- Authorized systems only



\## Technology Used



\- Windows Server 2019



\## What I Practiced



\- Installing and configuring Windows Server 2019

\- Managing users, groups, and permissions

\- Reviewing Windows Event Logs

\- Applying basic security-hardening practices

\- Reviewing network and remote-access settings

\- Documenting security observations and recommendations



\## What I Learned



Windows Server security involves managing user access, applying secure configuration practices, monitoring relevant events, and keeping systems updated. These practices help reduce risk and support incident investigation.
