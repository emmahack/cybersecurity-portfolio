\# Microsoft Sentinel Alert Investigation Lab



\## Objective



Use Microsoft Sentinel in a lab environment to practice reviewing security alerts and investigating related log activity.



\## Environment



\- Personal cloud lab or training environment

\- Test data and authorized systems only



\## Tool Used



\- Microsoft Sentinel



\## What I Practiced



\- Navigating the Microsoft Sentinel interface

\- Reviewing security incidents and alerts

\- Checking related log information

\- Investigating failed sign-in activity and other security events

\- Recording findings and suggested next steps



\## What I Learned



Microsoft Sentinel is a cloud-based SIEM tool that helps security teams collect, monitor, and investigate security information and alerts. Alert investigation requires reviewing available evidence, understanding the context, and recommending an appropriate response.



\## Ethical Scope



This work was completed in a personal lab or authorized training environment. It represents hands-on lab experience, not a claim of production SOC administration.
